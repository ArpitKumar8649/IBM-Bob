## 🎥 Recording Tips

1. **Pacing:** Keep voiceover conversational, not rushed. Pause briefly between features.
2. **Cursor:** Use a large, visible cursor. Highlight clicks with a subtle animation.
3. **Zoom:** Zoom in on key UI elements (agent dock, Story Bible, pitch deck) for clarity.
4. **Transitions:** Use quick cuts between features, not fades.
5. **Audio:** Record in a quiet room. Use a decent mic (even a phone mic is fine if close).
6. **Length:** Aim for 2:30–3:00. If it runs long, cut the Tone Transfer or Production Breakdowns section.

---

## 🛠️ Tools

- **Screen recording:** OBS Studio (free), Loom, or QuickTime
- **Editing:** DaVinci Resolve (free), iMovie, or CapCut
- **Voiceover:** Record separately, then sync in editing
- **Music:** Optional — add subtle background music (royalty-free)
